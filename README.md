# Gear Lands

**Пробуждение механизма** — играбельная браузерная 2D-метроидвания в стилистике steampunk.
Ты — Искра, киборг, очнувшийся на королевской свалке. Собери себя заново, сними печати трёх
хранителей, поднимись через цитадель и выступи против императора Аврелия.

Игра работает на Canvas 2D + Web Audio, без backend и без внешних CDN во время игры.
Интерфейс полностью на русском. Есть сенсорное управление.

## Быстрый запуск без установки

1. Скачай и распакуй ZIP проекта.
2. Открой **корневой `index.html`** двойным кликом в современном Chrome, Edge или Firefox.
3. Нажми «Пробудиться». Node.js, npm и локальный сервер не нужны.

Корневой `index.html` — автономная сборка: внутри уже есть код, стили, шрифты, 6 панорам,
15 музыкальных тем и 14 эффектов. Игра не обращается к сети. Звук включается после первого
нажатия — это требование браузеров к autoplay.

Сохранения хранятся в `localStorage` браузера. В режиме `file://` некоторые браузеры или
приватные окна могут запрещать постоянное хранение: игра продолжит работать, а статус
сохранения предупредит об этом. Для надёжных сохранений используй GitHub Pages или локальный
сервер. Не открывай `web/index.html` напрямую — это исходный шаблон для разработки.

## Разработка и сборка

```bash
npm ci
npm run dev       # Vite на 0.0.0.0:5173
npm run build     # dist/ для хостинга + автономный корневой index.html
npm run preview   # просмотр dist/ на 0.0.0.0:4173
```

Исходная страница лежит в `web/index.html`, код — в `src/`. Корневой `index.html`
генерируется командой `npm run build`; не редактируй его вручную.

Локальная проверка именно сценария GitHub Pages (сайт внутри подпапки репозитория):

```bash
npm run build
npm run preview:pages
# http://localhost:4174/Gear-Lands/
```

## GitHub Pages

Репозиторий уже подготовлен к публикации через GitHub Actions:

1. Открой **Settings → Pages → Build and deployment** и выбери источник **GitHub Actions**.
   Workflow также пытается включить Pages автоматически при первом запуске.
2. Запусти workflow из ветки `main`: pushes в `main` запускают его автоматически; можно также
   открыть **Actions → Deploy Gear Lands to GitHub Pages → Run workflow**.
3. Workflow устанавливает зависимости, прогоняет unit- и браузерные тесты, собирает `dist/`
   и публикует только готовую игру. Исходники и `node_modules` на сайт не попадают.
4. После зелёного запуска игра будет доступна по адресу вида
   `https://<владелец>.github.io/Gear-Lands/`. Для этого репозитория:
   `https://capitainpapai.github.io/Gear-Lands/`.

Все пути в production-сборке относительные, поэтому сайт работает и в корне Pages,
и в подпапке репозитория. Файл `.nojekyll` включён в `dist/`. Отдельный backend не нужен.

## Что внутри

- **Шесть связанных областей:** свалка → заброшенный город → мемориал → главный город →
  цитадель → вершина цитадели. Возврат в открытые области и быстрые переходы между маяками.
- **Законченный игровой цикл:** исследование, роботы-противники, опыт, шестерни, уровни,
  контрольные точки, смерть и возрождение, три хранителя и финальный босс с несколькими фазами.
- **Древо из 48 навыков:** корпус, клинок, механизмы и искра. У узлов есть стоимость,
  предпосылки и реальные эффекты в симуляции; очки выдаются за уровни, хранителей и секреты.
- **Мастерская:** улучшение здоровья, урона и запаса пара за шестерни.
- **Паркур:** переменная высота прыжка, coyote time, jump buffering, двойной прыжок,
  паровой рывок с неуязвимостью, прыжки от стен, реактивное парение и удар о землю.
- **Хранители открывают приводы:** Феррум — рывок и двойной прыжок; Хронос — магнитные
  захваты; Мнемоза — реактивное сердце. Печати запрещают обойти сюжетные врата.
- **Атлас и журнал:** состояние областей, задания, маяки, пять отголосков памяти с лором.
  Компас задания показывает направление и расстояние до ближайшей сюжетной цели.
- **Арены хранителей:** при входе в бой поднимается энергетическая печать, не дающая
  отступить в пропасть; после победы проход снова открыт.
- **Визуал:** шесть авторских панорам, процедурные артикулированные персонажи, вращающиеся
  шестерни, свет, туман, частицы, следы рывка, подготовка атак и тряска камеры.
- **Звук:** 15 оригинальных стереотем (~14 минут) и 14 эффектов. Фортепианные, струнные,
  духовые, колокольные и металлические тембры, аддитивный синтез и реверберация. **Без 8-bit / chiptune.**
  Музыка переключается между исследованием, боем, боссом, отдыхом и эпилогом; любую тему можно
  послушать в плеере внизу экрана.
- **Сохранение:** автоматически в `localStorage` этого браузера; ручное сохранение в настройках.
  Новая история заменяет текущий прогресс. Облачной синхронизации нет.
- **Комфорт:** громкость музыки/эффектов, отключение тряски, режим меньшего движения,
  полноэкранный режим, клавиатурная навигация в диалогах.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `A` / `D`, стрелки |
| Прыжок; повторное нажатие — воздушный прыжок | `Space`, `W`, ↑ |
| Клинок | `J` |
| Паровой рывок | `K`, левый `Shift` |
| Паровой заряд | `L` |
| Починка за пар | `F` |
| Маяк / отголосок памяти | `E` |
| Удар о землю после изучения навыка | `S`, ↓ в воздухе |
| Древо навыков | `Tab` |
| Атлас / журнал | `M` |
| Пауза / закрыть окно | `Esc` |
| Руководство | `H` |

На узких экранах и устройствах с coarse pointer появляются сенсорные кнопки движения, прыжка,
удара, рывка, взаимодействия, починки и пара. Починка прерывается попаданием; попадания по
врагам возвращают пар. Отдых у маяка восстанавливает ресурсы и сохраняет путь.

## Проверки

```bash
npm test                 # 9 unit-тестов: древо, статистика, мир, коллизии, аудио-манифест
npx playwright install chromium
npm run test:e2e         # сборка + 8 игровых сценариев + 2 сценария распространения
npm run build
npm run test:release     # только file:// и GitHub Pages subpath (после сборки)
```

Покрыты пробуждение, движение, прыжок, бой, изучение и сохранение навыков, награды хранителей,
атлас, плеер, смерть/возрождение, мобильная раскладка, циклы атак всех боссов, победа над
императором и вертикальный рендер цитадели. Отдельный детерминированный сценарий проходит
весь маршрут обычными действиями движения/прыжка/рывка/атаки/починки/отдыха: четыре босса,
все маяки, 22 площадки шахты цитадели и финал на вершине.

Release-тесты открывают настоящий корневой `index.html` через `file://` без сети и проверяют
графику, музыку, управление и сохранение после перезагрузки. Второй сценарий раздаёт `dist/`
из подпапки `/Gear-Lands/` и проверяет, что все ресурсы загружаются относительными путями.
Можно задать свой Chromium через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

## Структура

- `index.html` — готовая автономная игра для двойного клика; генерируется сборкой.
- `web/index.html`, `web/main.js` — исходный HTML-шаблон и вход Vite.
- `src/game/engine.js` — симуляция, бой, AI, прогрессия, сохранения.
- `src/game/renderer.js` — Canvas-рендер, параллакс, персонажи, эффекты.
- `src/game/world.js` — шесть областей, платформы, противники, боссы, маяки.
- `src/game/skills.js` — 48 узлов и вычисление характеристик.
- `src/game/assets.js`, `src/game/storage.js` — единые пути ресурсов и безопасное локальное хранение.
- `src/audio/audio.js` — ленивая загрузка, кроссфейды, контекстный саундтрек, эффекты.
- `src/main.js`, `src/styles.css` — HUD, древо, атлас, плеер, настройки, доступность.
- `scripts/export-standalone.mjs` — упаковка кода, шрифтов, графики и звука в один `index.html`.
- `scripts/serve-pages.mjs` — локальная симуляция GitHub Pages в подпапке `/Gear-Lands/`.
- `scripts/synthesize_audio.py` — исходный генератор музыки и эффектов.
- `.github/workflows/pages.yml` — тестирование и публикация GitHub Pages.
- `public/art/`, `public/audio/` — локальные игровые ассеты.

Визуальные панорамы созданы генеративно для проекта; персонажи и окружение рисуются кодом.
Hollow Knight использован только как жанровый ориентир: его ассеты, персонажи и музыка не используются.
